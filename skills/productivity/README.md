# Productivity

General-purpose skills that are not tied to a specific programming language or framework.

## Model-invoked

These skills can be invoked by the user or selected automatically when the request matches their descriptions.

- **[say-it-clearly](./say-it-clearly/SKILL.md):** Draft, revise, or audit useful prose that respects the reader and preserves meaning.
- **[hand-off-work](./hand-off-work/SKILL.md):** Preserve exact state and evidence so unfinished work can resume safely.
- **[guide-manual-steps](./guide-manual-steps/SKILL.md):** Guide only the steps that require a person's identity, credentials, or physical presence.
- **[write-a-personal-essay](./write-a-personal-essay/SKILL.md):** Assemble a first-person essay from an author's fragments without losing voice or detail.
- **[generate-chaitanya-essay-images](./generate-chaitanya-essay-images/SKILL.md):** Produce and verify the chaitanya.gg ink illustration system.
- **[work-unattended](./work-unattended/SKILL.md):** Run to completion under a fixed stop predicate, autonomy boundary, and stall rule.
- **[log-decisions](./log-decisions/SKILL.md):** Keep an audited append-only trail of judgment calls during long runs.
- **[capture-the-lesson](./capture-the-lesson/SKILL.md):** Convert a task's failures into at most three durable structural changes.
