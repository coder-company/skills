# dated-skill fixture

A one-skill collection whose SKILL.md mixes prompt text written for an older model (pressure language, step choreography, anti-narration and anti-formatting rules, a numeric word cap, a pinned model name and incident ID, hedged requirements, a trigger list of near-synonyms) with context that must survive any refit: the release script contract, the token requirement, the rollback command, and the billing-window constraint with its reason.

`evals/cases.json` asserts the old 120-word, no-bullets report shape, so removing that rule without updating the case is an out-of-band dependency the refit has to catch.
